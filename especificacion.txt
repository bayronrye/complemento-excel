[2. PRINCIPIOS FUNDAMENTALES "ANTIGRAVITY" (ZERO-OVERHEAD)]
El agente debe operar bajo directrices estrictas de cero fricción y latencia mínima:

2.1. Payload Quirúrgico (Contexto Estricto):
  - PROHIBIDO transferir hojas completas mediante worksheet.getUsedRange().
  - Extraer únicamente el rango activo delimitado: context.workbook.getSelectedRange().
  - Incluir automáticamente solo una fila previa de cabecera si la selección no la tiene.
  - Comprimir celdas nulas o vacías en matrices compactadas (ejemplo: usar token "_" para nulls).

2.2. Sincronización Atómica en Office.js:
  - PROHIBIDO invocar "await context.sync()" dentro de bucles o iteradores.
  - Regla 1-Sync de Lectura: Cargar todas las propiedades requeridas (formulas, values, rowCount, columnCount, rowIndex, columnIndex) en una sola sincronización inicial.
  - Procesamiento en memoria JavaScript / Motor local.
  - Regla 1-Sync de Escritura: Asignar todas las matrices de resultados y llamar un único context.sync() final.

2.3. Hilo de Ejecución No Bloqueante:
  - Separar la manipulación del DOM de Excel del ciclo de red mediante microtareas asíncronas.
  - Notificar estado en la UI ("Analizando rango...", "Calculando fórmulas...") usando requestAnimationFrame.

2.4. Malla de Seguridad y Reversibilidad (Rollback):
  - Capturar una instantánea en memoria (snapshot de values y formulas) del rango objetivo antes de cualquier mutación.
  - En caso de detección de errores masivos de cálculo (#REF!, #¡VALOR!, #N/A), restaurar automáticamente el snapshot previo.

[6. MOTOR DE RELLENO RÁPIDO EN TASKPANE.JS / GEMINI-AGENT.JS]
Función JavaScript para ejecutar el forward-fill localmente en un solo ciclo de sincronización:

async function runFastBlankFill(targetAddress) {
  return await Excel.run(async (context) => {
    const sheet = context.workbook.worksheets.getActiveWorksheet();
    const range = sheet.getRange(targetAddress);
    
    // Lectura en 1 solo ciclo
    range.load(["formulas", "values", "rowCount", "columnCount", "rowIndex", "columnIndex"]);
    await context.sync();

    const formulas = range.formulas;
    const startRow = range.rowIndex;
    const startCol = range.columnIndex;
    let modified = false;

    for (let r = 0; r < range.rowCount; r++) {
      for (let c = 0; c < range.columnCount; c++) {
        const val = formulas[r][c];
        // Evaluar si es celda vacía y tiene celda superior en el rango o arriba de él
        if ((val === "" || val === null) && (r > 0 || startRow > 0)) {
          const colLetter = toExcelCol(startCol + c);
          const aboveRow = startRow + r; // Fila superior 1-based
          formulas[r][c] = `=${colLetter}${aboveRow}`;
          modified = true;
        }
      }
    }

    if (modified) {
      range.formulas = formulas;
      // Escritura en 1 solo ciclo
      await context.sync();
    }
    return { success: true, target: targetAddress, modified };
  });
}

function toExcelCol(index) {
  let col = "";
  while (index >= 0) {
    col = String.fromCharCode((index % 26) + 65) + col;
    index = Math.floor(index / 26) - 1;
  }
  return col;
}
